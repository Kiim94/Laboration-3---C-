# Laboration 3 i C#
Uppgiften går ut på att skapa en konsol applikation som fungerar som en gästbok.

## Krav för uppgiften
- Ha möjlighet att lägga till, ta bort samt visa alla poster.
- Ett menysystem där man som användare kan välja vad man vill göra.
- Vid lägg till inlägg ska man kunna skriva ägare av inlägget samt själva inlägget
  - Dessa fält får inte stå tomma.
- När inlägg tas bort ska det frågas efter valt index innan inlägget raderas
- Inläggen ska serialiseras/deserialiseras samt sparas på fil antingen binärt eller som json, så att tidigare inlägg finns lagrad.
- Felhantering så att inmatningsfält inte är tomma
- Skärmen ska skrivas om efter varje menyval.
